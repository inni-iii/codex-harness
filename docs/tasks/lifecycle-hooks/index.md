# lifecycle-hooks 문서 지도

작업 목적: 세션 범위 Stop 알림·Interrupt 재개·선택적 정적 검사·명백한 원격 쓰기 감지 훅 연결

현재 상태·완료 여부와 실행 근거는 task/evidence 원본을 확인한다. 필요한 문서만 선택해 읽는다.

| 문서 | 역할·읽을 때 |
|---|---|
| [생명주기 훅 구현 기록](notes.md) | 작업 중 결정·발견·실패·검증 결과와 인수인계를 확인한다 |
| [생명주기 훅 구현과 검증 범위](result.md) | 당시 작업의 관측 결과·검증 범위·남은 한계를 확인한다 |
| [작업 계약](task.json) | 목표·수용 기준·현재 상태·증거·다음 행동을 확인한다 |
| [완료 검토](review.json) | 당시 기준별 판단·근거·한계와 자체/독립 검토 구분을 확인한다 |
