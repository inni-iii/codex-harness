# research-data-analysis 작업 지도

필요한 항목만 읽는다. 현재 상태와 완료 판단은 task/evidence 원본을 확인한다.

| 문서 | 역할·읽을 때 |
|---|---|
| [작업 계약](task.json) | 목표·범위·수용 기준·현재 상태·검증 근거와 다음 행동을 확인한다 |
| [작업 기록](notes.md) | 중요한 결정·실패·수정·검증·인수인계를 확인한다 |

- [요청](request.md): 분석 방법론 조사와 스킬 보완의 현재 범위

- [조사 근거](sources.md): 공식/원저의 읽은 범위·채택/제외·접근 한계
- [설계](design.md): 분석 절차·선택/flow와 검증의 보완 계약

- [분석·연결 사례](scenarios.md): CSV 분모/집단 구성과 중첩JSON 합계의 실제 계산·한계

- [조사·보완 결과](report.md): 방법론 비교·하네스 적용·실행 근거와 한계를 확인한다
