# CSV·JSON 데이터 분석 방법론 조사와 research 보완

2026-11-04. [공식/원저 근거와 확인 범위](sources.md)를 조사해 기존 research에 질문 기반 데이터 분석을 보완했다. 별도 스킬·데이터 분석 엔진·ML/설치를 의무화하지 않았다.

## 방법론을 어떻게 조합하는가

| 방법론/원칙 | 맡는 일 | 이 하네스에 적용한 범위 |
|---|---|---|
| PPDAC | 질문·계획·자료·분석·근거 있는 결론을 연결 | 작은 파일 분석의 가벼운 흐름으로 참고한다. 교육적 설명을 모든 프로젝트의 의무 표준으로 주장하지 않는다. |
| CRISP-DM | 목적·자료 이해/준비·모델·평가·활용의 반복 | 큰 분석의 단계/되돌아감을 참고한다. 요약·탐색만으로 답하면 모델·배포를 강제하지 않는다. |
| 데이터 품질6차원 | 자료가 분석 목적에 맞는지 판단 | 결측·고유성·일관성·시점·형식과 현실 정확성의 확인 범위를 나눈다. 단일 점수로 모든 자료를 합격시키지 않는다. |
| Tidy Data | 변수·관측·관측 단위의 구조를 명확히 함 | CSV와 중첩JSON의 키/부모·자식·단위와 변환 총계를 보존한다. |
| EDA | 분포·관계·추세·이상치·방법 가정을 탐색 | 숫자 요약과 적절한 표/그래프를 대조하고 왜도·층별 차이·시간 구조를 본다. |
| 추론/효과·불확실성 | 관측된 차이에 대한 해석의 범위를 정함 | 표본/의존성·탐색/확인 분석·효과 크기·구간·다중 비교를 점검한다. p-value만으로 중요성/인과를 단정하지 않는다. |
| 예측 평가·누출 방지 | 새 자료에서 성능을 평가 | 예측이 필요한 경우만 기준선과 비교하고 평가 자료를 분리한 뒤 학습 자료에서 전처리를 학습한다. |
| AQuA·재현 가능한 분석 | 계산이 맞는지와 질문에 맞는지를 따로 검토 | 목적·위험에 맞는 검증, 입력/변환/결과·민감도·한계를 남긴다. 조직 역할/추가 승인을 기계적으로 가져오지 않는다. |

위 조합과 질문별 방법 표는 이 하네스의 적용 설계다. 단일 원문이 이 전체 절차를 그대로 규정한다고 하지 않는다. 각 출처의 맥락·읽은 구간·제외 사항은 sources에 분리했다.

## 실제 수행의 핵심

질문·판단·대상/기간·관측 단위와 지표/분모를 정한 뒤 원본을 보존하며 실제로 읽는다. 자료형·결측·중복·오류·범위·관계와 조인/전개를 확인한다. 현황/집단 차이/시간/코호트·퍼널/관계/추론/텍스트·사건/예측/인과 질문에 필요한 방법만 선택한다. 전체/표본·실제 처리 건수와 조건, 다른 집계/처리에서의 민감도, 관측과 해석·다음 행동을 구분해 재현 근거와 연결한다.

큰 파일을 모델에 통째로 전달하지 않는다. 코드로 필요한 자료·집계·품질 근거를 계산하고 관련 결과만 읽는다. 원본 해시·읽기 옵션·정제 전후 건수와 지표별 분모를 남겨 파일 앞부분만 읽고 전체를 분석했다고 하는 오류를 피한다.

## 반영한 연결

- research의 native 설명과 작업 표에 데이터 분석을 추가했다. 데이터 분석 상세 참조와 선택형 계약 양식을 연결했다.
- data-analysis/dataset-analysis/eda/data-quality 주제로 해당 절차를 읽도록 등록했다. *.json 경로를 광범위 trigger로 추가하지 않아 설정·패키지·task JSON 편집과 구분한다.
- research:analyze-data와 계획/조사에서의 호출, 선택적 실험·검토·문서 정리 경로를 등록했다. 질문/원본·실제 계산·반례·한계는 에이전트가 판단하며 flow가 통계적 정답을 자동 승인하지 않는다.
- 같은 기능의 기존 문서를 우선 갱신하고 폴더 지도·읽기 조건을 연결한다. 단순 조회마다 새 프로젝트/보고서·task를 만들지 않는다.

## 실행 근거와 한계

[합성 분석 사례](scenarios.md)에서24행 CSV의 중복·필드 오류·지표별 분모·층별 비교와 중첩 주문JSON의 단위/총계 오류를 실제 계산했다. 원본 두 파일의 해시는 유지됐다. 선택/비선택·flow 호출/복귀·관측 근거가 없는 성공 차단4개를 실행했다. 등록 검사와 최종 통합의 결과는 task evidence와 notes에 연결한다.

이는 작성 에이전트의 자체 분석·검토와 합성 사례다. 실제 사용자 데이터, 모든 통계 기법, 인과 효과·모델 성능·독립 에이전트 품질이나 토큰 절감률을 측정한 것은 아니다. 관측한 pandas/scikit-learn/SciPy 문서 버전을 실제 설치/지원 버전으로 고정하지 않았다. 외부 원문 접근 실패와 읽은 초록/본문 범위를 sources에서 구분했다.
