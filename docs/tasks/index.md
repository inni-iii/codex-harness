# 작업 기록 지도

목표에 맞는 작업만 선택해 task.json의 현재 상태·수용 기준·근거를 읽고, 재개/실패 맥락이 필요하면 notes.md를 읽는다.
아래는 탐색용 요약이다. 다른 세션의 진행 상태를 별도 복제하지 않는다.

| 질문·작업 | 기록·근거의 출발점 |
|---|---|
| 문서 관리·위키 스킬을 왜/어떻게 만들었나 | [task](docs-maintenance/task.json), [과거 조사·검증](docs-maintenance/notes.md) |
| 인덱스·설계에서 구현까지의 연결 보완 | [task](docs-index-review/task.json), [이번 점검](docs-index-review/notes.md) |
| 목표·마일스톤 기반 작업 분해와 갭 재평가 보강 | [task](top-down-planning/task.json), [검토·검증 기록](top-down-planning/notes.md) |
| REASONS 설계·정렬·구현 진입 및 docs 변경 분류 구현 | [task](reasons-design-gates/task.json), [실행/검증 기록](reasons-design-gates/notes.md) |
| SPDD·REASONS 기반 의도/경계·docs/하네스 보완 조사 | [task](spdd-reasons-research/task.json), [조사 기록](spdd-reasons-research/notes.md) |
| 스킬:라우트 그래프·호출/복귀·조건부 전이·재진입 | [task](skill-route-graph/task.json), [구현·검증 기록](skill-route-graph/notes.md) |
| 학습·브라우저 상세 절차 소유권과 선택 읽기 정리 | [task](skills-consolidation/task.json), [정리·검증 기록](skills-consolidation/notes.md) |
| 지식·스킬·환경·설정 기능 보강 | [task](harness-capabilities/task.json), [작업 기록](harness-capabilities/notes.md) |
| 보안 검사기의 반복 검토·수정 근거 | [task](security-convergence-review/task.json), [검토 기록](security-convergence-review/notes.md) |

항목이 없으면 이 폴더의 task.json에서 목표·종류를 검색한다. 전체 notes·review·검사 로그를 매번 읽지 않는다.
작업을 생성·이동·정리할 때 관련 행을 추가·수정한다. 현재 제품 계약은 프로젝트 문서로, 실행 결과는 각 evidence 원본으로 돌아간다.
