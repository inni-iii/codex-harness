# 하네스 연결 전반 진단

2026-11-04 현재 소스 기준. 전체 연결이 모두 끊긴 상태는 아니다. 확인한 단절은 검사 등록1건(F1), 근거 이식 경로1건(F2), 과거 로컬 근거 이관1건(F3)이다. 실제 실행을 막는 F1/F2를 먼저 처리해야 한다. 이번 요청에서는 실행 코드/타 작업/설정을 수정하지 않았다.

## 의도한 보류와 미확인

- UserPromptSubmit의 자동 모델 라우팅은 명시적으로 보류했다. 일반 작업의 필수 연결이 아니며 run/chat을 실제 모델로 새로 실행하지 않았다.
- 내장 웹검색에는 도구 훅 이벤트가 없어 research의 검색 전후 절차로 연결한다. MCP 훅이 웹검색까지 실행된다고 주장하지 않는다.
- 브라우저 MCP/Chromium·AgentShield 실엔진·프로젝트 DB/API/제품 E2E는 선택/프로젝트별 준비 사항이다. 이번 진단에서 설치하거나 서비스 실행을 추가하지 않았다.
- source-only 복사본의 F2, 과거 근거 F3와 별개로 현재 main doctor와 agent-config는 통과했다. doctor 통과가 전체 연결/제품 요구 충족을 증명하지 않는다.
- Claude와 Codex 접근 가능한 전체 기록을 검색 범위로 삼고 관련 Codex 원문을 날짜와 함께 확인했다. 관련 Claude 결정 원문은 찾지 못했고 Claude plans는 없으며 Codex archived JSONL은0개였다. 원문을 읽지 않은 기록 전체를 검토 완료했다고 주장하지 않는다.

## 보존한 근거

실제 명령/종료 코드·선택/해시/보고서 위치는 task.json의 typed evidence와 [수행 기록](notes.md)에 연결했다. 세부 JSON/로그/현재 MCP 응답 메타데이터/복구 위치는 .runtime/harness-connection-audit 아래에 보존했다. 기존 전체 검사 로그는 원래 snapshot에 유지하고 실패를 통과로 재분류하지 않았다. 검토는 작성 에이전트의 자체 검토이며 독립 평가가 아니다.
