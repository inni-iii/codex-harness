# document-delivery-defaults 작업 지도

필요한 항목만 읽는다. 현재 상태와 완료 판단은 task/evidence 원본을 확인한다.

| 문서 | 역할·읽을 때 |
|---|---|
| [작업 계약](task.json) | 목표·범위·수용 기준·현재 상태·검증 근거와 다음 행동을 확인한다 |
| [작업 기록](notes.md) | 중요한 결정·실패·수정·검증·인수인계를 확인한다 |
| [요청 원문](request.md) | 이번 사용자 요청·정정과 수행 범위의 근거를 읽는다 |
| [변경 설계](design.md) | 기본 절차의 의도·범위·선택/검증 경계를 확인한다 |
| [연결·시나리오 검토](results.md) | 실제 선택 회귀 관측과 작성자 자체 반례 검토·한계를 읽는다 |
| [단계별 검토 정정](request-stage-review.md) | 자동 진행 해석을 대체한 최신 사용자 원문과 범위를 읽는다 |
| [단계별 설계](design-stage-review.md) | 사용자 검토·대기·진행 전환의 현재 변경 계약을 읽는다 |
| [범위 밖 후속](follow-up.md) | 전체 검사에서 발견한 lifecycle fixture 오류와 후속을 읽는다 |
| [현재 단계별 검토 결과](stage-review-results.md) | 사용자 검토·대기·수정·자율 전환의 자체 시나리오와 실제 검사 한계를 읽는다 |
