# 단계별 사용자 검토 정정

2026-11-04T08:44 이후 현재 대화 사용자 원문: “근데 그건 너무 한 번 명령으로 끝까지 구현하는거잖아. 나는 저 8단계를 하나씩하고 내가 직접 보고 이러고싶어”

전체 위임을 원하는 것으로 해석한 이전 지침을 수정한다. 프로젝트 문서와 구현 요청의 기본은 1단계만 수행하고 결과를 보여준 뒤 대기한다. 사용자가 다음 진행을 지시하면 다음 단계로 간다. 구현도 기능별 구현→사용자 검토→검증→사용자 검토→다음 작업 판단으로 진행한다. 명시적인 자율 진행 위임만 해당 범위에서 자동 진행을 허용한다. 현재 지침 수정은 사용자가 요청한 범위에서 완료한다.
