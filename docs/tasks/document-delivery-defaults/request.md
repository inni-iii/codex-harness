# 현재 요청과 범위

2026-11-04: 사용자는 요구 문서에서 시작하는 전체 8단계를 안내 체크리스트로 구성하고, 실제 구현은 기능 묶음마다 실행·검증 후 다음 작업을 선택하는 것을 기본으로 원한다. 매번 긴 지시를 반복하지 않는 것이 목표다. 직전 a-to-z 무검증 일괄 구현 우려를 유지한다. 최신 지시 “아니 그냥 여기서 계속 만들어”에 따라 현재 체크아웃에서 진행하며 기존 변경은 보존한다.

문서만 전달/설계만 요청은 구현 권한이 아니다. 전체 구현을 맡긴 범위에서는 일상적 재승인을 추가하지 않는다. 중요한 미결정·충돌·필수 환경 차단은 숨기지 않는다.
