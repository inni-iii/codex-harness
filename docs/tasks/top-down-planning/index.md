# top-down-planning 문서 지도

작업 목적: 사람이 정한 목표·마일스톤에서 요구·성공 조건·갭·작업을 연결하고 작업 전후 현재 근거로 계획을 갱신하는 하네스 절차 보강

현재 상태·완료 여부와 실행 근거는 task/evidence 원본을 확인한다. 필요한 문서만 선택해 읽는다.

| 문서 | 역할·읽을 때 |
|---|---|
| [목표·갭 계획 보강 기록](notes.md) | 작업 중 결정·발견·실패·검증 결과와 인수인계를 확인한다 |
| [목표에서 작업으로 이어가는 계획 보강](result.md) | 당시 작업의 관측 결과·검증 범위·남은 한계를 확인한다 |
| [작업 계약](task.json) | 목표·수용 기준·현재 상태·증거·다음 행동을 확인한다 |
| [완료 검토](review.json) | 당시 기준별 판단·근거·한계와 자체/독립 검토 구분을 확인한다 |
