2026-11-04 현재 접근 가능한 코드·설정·원문과 실제 로컬 실행을 대조했다. 기존 감사의 검사 등록/실패 근거 이식 문제는 해결됐고, 이번에는 동시 인덱스 쓰기와 worktree 소스 입력 경계의 결함 두 건을 실제로 재현해 보완했다. 전체 등록 검사의 최종 결과는 task evidence와 notes에서 확인한다.

## 연결을 확인한 범위

| 영역 | 확인과 결과 | 실제 경계 |
|---|---|---|
| 요청 → 스킬/참조 | backend·frontend/E2E·Docker·환경·문서·review 6종을 context --read로 확인했다. 관련 원문이 선택되고 읽혔다. | 자연어 스킬 선택 정확도나 모든 작업의 무오류를 측정한 것이 아니다. |
| 스킬 → flow | 실제15개 스킬·37개 라우트·111개 이동 계약을 로드하고 경로·문서·필수 호출·종료 조건을 대조했다. | 직접 start하는 조사/검토 라우트의 외부 입구를 그래프의 누락으로 분류하지 않는다. flow는 작업 자동 실행기가 아니다. |
| CLI → 실행/검사 | 검사 전체 계획에 미등록 경로가 없고 공개 entrypoint와 등록 명령을 현재 코드/실제 회귀와 대조했다. | 선택적 run/chat의 새 모델 호출·인증/과금 경로는 실행하지 않았다. |
| 문서 → 선택 읽기 | 폴더별 index·역할/하위 지도와 생성기·관련 조상 지도만 읽는 회귀를 확인했다. | 문서 역할의 의미·최신성은 원문 검토가 필요하다. 전체 본문이나 형제 지도를 모델에 펼치지 않는다. |
| 지식 → 재사용 | 현재 채택된1개 규칙을 package.json/환경 맥락에서 실제 선택했다. | 후보/위키/과거 대화를 자동 채택하지 않는다. |
| 작업 → 검증·완료·재개 | 현재 hook task 연결/미해결 조회, 증거/리뷰/flow 연결과 6종 합성 pilot을 실제 실행했다. | 합성 pilot은 독립 에이전트 품질 평가나 실제 서비스 E2E가 아니다. |
| 설정 → 도구 | doctor의 MCP/훅 설정·entrypoint·현재 pending 상태를 대조했다. | 원격 MCP/로그인/브라우저·실서비스 연결을 이번 로컬 검사만으로 새로 검증했다고 하지 않는다. |
| 격리 → 통합 | 별도 worktree에서 수정 전/후를 보존하고 실제 변경 파일의 기준 SHA를 확인해 합친다. | 포트·DB·브라우저 데이터 격리와 원격 쓰기 권한은 별도이며 SSH는 계속 읽기 전용이다. |

## 현재 남은 범위

- 과거 로컬 증거63개 참조가11개 작업에서 현재 레포에 없다. 이전 감사에서 원본 위치와 해시 일치를 확인한 이관 항목이다. 당시 근거를 현재 재검증으로 바꾸거나 누락을 현재 기능 실패로 단정하지 않는다. 원문·로그 복원은 별도 보존 작업이며 이번 두 코드 수정으로 해결됐다고 표시하지 않는다.
- 다른 세션에서 docs/<프로젝트>/기능별 문서 배치·저장/인덱스/선택 연결을 구현 중이다. 현재 승인 원문과 task 범위를 확인했고 그 작업의 자체 완료 판정을 대신하지 않는다. 이번 통합 검사는 관측한 결합 상태를 대상으로 한다.
- 활성 서비스 프로젝트가 없어 실제 앱·DB·외부 서비스 기동 후 사용자 입력→결과까지 확인한 서비스 사례는 없다. 앞서 논의한 프로젝트 시작 절차와 설정 준비/실제 앱 완료의 구분을 유지한다. 하네스 회귀 통과가 서비스 시작 검증을 대신하지 않는다.
- 일반 대화창의 자동 모델 라우팅은 사용자가 보류한 항목이다. AgentShield 실엔진·선택 브라우저·외부 인증/서비스도 현재 필수 연결로 바꾸지 않는다.

검토는 현재 작업 에이전트의 자체 검토다. Claude/Codex 접근 가능한 전체 기록을 검색 범위로 삼고 관련 원문을 재사용/추가 확인했다. 관련 Claude 하네스 결정 원문은 발견하지 못했으며 Claude plans가 없고 Codex archived JSONL은0개다. 과거 원문 전체를 모두 읽었다고 주장하지 않는다.
