# 문서 인덱스

이번 질문·프로젝트·단계에 맞는 행만 고른 뒤 해당 하위 지도와 필요한 원문을 읽는다.
링크된 문서 전체를 한 번에 읽지 않는다. 명시된 필수 지침·프로젝트/보안 문서는 유지한다.

| 지금 필요한 것 | 다음 지도·원문 | 구분 |
|---|---|---|
| 새 주제의 요구→설계→구현 순서 | [프로젝트 시작](projects/README.md) | 서비스 프로젝트 출발점 |
| 진행 중 프로젝트의 계약·다음 단계 | `docs/projects/<이름>/index.md` | 프로젝트 생성 시 만들어지는 지도; 해당 프로필로 선택 |
| 기존 작업의 결정·실패·검증·재개 | [작업 지도](tasks/index.md) | 현재 상태는 각 task.json·근거가 정본 |
| 학습한 규칙·반복 정정·공통화 | [지식 관리](../tools/harness/docs/knowledge.md) | catalog는 필요한 범위·상태로 검색 |
| 하네스 명령·설정·검증·설계 근거 | [하네스 문서 지도](../tools/harness/docs/index.md) | 사용법과 과거 초안을 구분 |
| 문서 정리·최신화·위키·인덱스 유지 | [문서 관리 스킬](../.agents/skills/docs-maintenance/SKILL.md) | 실제 요청의 절차만 선택 |

## 선택해서 읽는 순서

1. 질문에서 프로젝트·단계·필요한 결정을 정한다. 이미 지정된 정본 경로가 있으면 바로 관련 부분을 읽는다.
2. 필요한 하위 지도 하나에서 목적·읽을 조건·현재/초안/과거 상태를 확인한다.
3. 선택한 정본의 관련 절을 읽고, 판단에 필요한 연결 대상·반대 근거·원본만 더 읽는다.
4. 지도에 없거나 링크/상태가 오래됐으면 관련 폴더에서 파일명·제목·용어를 좁혀 검색한다. 목록이나 요약만 보고 원문을 읽었다고 하지 않는다.

생성·이동·삭제·상태 변경 시 해당 하위 지도를 갱신한다. 이 최상위 지도에는 개별 문서 본문·전체 task 목록을 복제하지 않는다.
인덱스는 탐색 보조다. 과거 Claude·Codex 원문 확인 요구나 사실·구현 검증을 대신하지 않는다.
