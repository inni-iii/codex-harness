# 분석 계약과 결과

기존 기능 정본이 있으면 해당 문서를 갱신한다. 짧은 조회는 필요한 항목만 적는다.

## 질문·판단

- 답할 질문과 결과를 사용할 결정:
- 대상 개체/모집단·표본·기간·비교 기준:
- 한 레코드의 관측 단위·키·단위/통화·시간대:
- 주 지표·분모·실무적으로 의미 있는 차이 또는 미결정:

## 입력과 처리

- 입력 별칭·출처·해시·크기·확인일·수집/접근 한계:
- 전체/표본·읽기 옵션·처리 건수와 오류/제외:
- 자료형·결측·중복·유효성/일관성·정확성 확인 범위:
- 정제·조인·배열 전개 전후 건수/키/총계와 지표별 분모:
- 원본 보존과 민감 정보 출력/공유 범위:

## 방법과 관측

- 선택한 방법과 대안/제외 이유·관련 가정:
- 탐색/확인 분석 구분과 살펴본 비교:
- 주요 표/그림·수치·기간·분모·효과/불확실성과 계산 근거:
- 다른 집계·처리·기간/층화에서의 민감도와 반례:

## 해석·다음 행동·재현

- 관측 사실 / 가정이 포함된 해석 / 실행 제안:
- 답하지 못한 질문·자료/설계 한계·추가 확인:
- 코드·명령/cwd·도구 환경·입력 버전·출력 위치와 실제 실행 결과:
- 자체/독립 검토 구분과 원본 해시 보존:
