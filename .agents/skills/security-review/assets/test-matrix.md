# 보안 검사 행렬

보호 조건에서 테스트를 도출한다. 아래 빈 행은 실행된 테스트가 아니다.

| 사례 ID | 보호 조건 | 정상/거부/오류/경합 | 입력·주체·전제 | 예상 응답·금지할 부작용 | 실제 처리 경계/테스트 | 결과·근거 |
|---|---|---|---|---|---|---|
| 작성 필요 | | | | | | 미실행 |

- 대상 코드 상태 / 검사일:
- 명령·cwd·격리 환경 / 외부 호출 대역:
- 실행 수·실패·skip / 적용 제외와 이유:
- 수정 전 재현·수정 후 같은 재현·정상 회귀:
- 실제 모델·브라우저·DB·외부 제공자 중 사용한 것과 대체한 것:
- 미해결 발견 ID / 남은 환경 조건:

HTTP 상태만으로 무부작용을 추정하지 않는다. 저장 값·파일·호출 횟수·로그도 관련 조건에 맞게 관측한다.
