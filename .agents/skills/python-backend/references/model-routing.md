# 모델 라우팅과 실행 경계

이 레포의 모델 실행·프로세스·프롬프트 훅을 다룰 때 [실행 안내](../../../../tools/harness/docs/execution.md)를 읽는다.
추천만 하는 route와 실제 수행하는 run/chat, 호스트 훅의 인수인계·신뢰·권한·검증 한계를 구분한다.
기본 작업은 현재 대화창 모델로 수행하며 라우터 호출은 선택 사항이다. 대화창의 자동 라우팅·인수인계 훅은 미등록 상태다.
run/chat을 명시적으로 선택한 경우에만 그 명령 내부에서 라우팅 후 실행한다. 내부 비모델 명령마다 모델을 호출하지 않는다.
