# 재사용할 문제 해결 기록

- 날짜·기록 ID:
- 상태: candidate / evaluated / adopted / superseded
- 적용 범위: 해당 프로젝트 / 공통 하네스
- 언제 읽을지: 작업 종류·주제·영향 경로
- 문제와 실제 발생 조건:
- 원인과 확인한 원문·버전:
- 해결 또는 제안:
- 적용하면 안 되는 조건·남은 한계:
- 확인한 재현/회귀 사례·결과·근거:
- 실제 결함 ID·테스트/시나리오 위치·실제 검사 수집 조건:
- 수정 전 실패·수정 후 통과의 증거 ID/보고서:
- 자동화 불가/미실행 사유와 남은 확인:
- 연결한 스킬/프로젝트 규칙·context 조건:
- 대체한/대체된 결정과 날짜:

관측·추론·사용자 결정을 구분한다. 자기 평가 점수와 반복 횟수만으로 채택 상태를 정하지 않는다.
공유 기록에는 비밀값·전체 대화·개인 컴퓨터의 경로를 넣지 않는다.
