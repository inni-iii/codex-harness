# 작업 인수인계

작업의 notes.md에 필요한 항목만 옮긴다. 실제로 확인한 내용과 미확인을 구분한다.

- 기록 날짜:
- 작업 목표·범위·현재 사용자 제약:
- 상위 마일스톤·요구·갭 ID와 계획 정본/기준 날짜의 위치(해당할 때):
- 현재 상태: 진행 중 / 보완 필요 / 환경 차단 / 요청 범위 완료
- 이어서 읽을 자료·코드·계약의 레포 상대경로:
- 현재 코드 상태와 인수인계 이후 달라진 부분:
- 의미 있는 작업 묶음·이번에 알린 검증 범위·checkpoint:
- E2E 수행 여부·결과·미룬 검사와 재개 시점:
- 세션 격리 위치·기준 커밋·통합 검토와 충돌 결정:
- 확정 결정·근거·미결정:
- 실패/탈락한 방법·당시 조건·재검토 조건:
- 남은 문제와 수용 기준별 미확인:
- 이전 갭 대비 해결·잔여·신규·다시 열림·미확인, 실제 근거와 목표 변경 여부:
- 다음 한 행동: 파일/함수/실행 명령과 관측할 결과
- 필요한 환경·실행 전제와 재현 방법:

| 수용 기준 | 상태 | 실제 명령·cwd·대상 상태 | 결과·근거 위치 |
|---|---|---|---|
| 해당 작업의 관측 가능한 기준 | 충족/불충족/미확인 | 실행했을 때만 기록 | 새 환경에서 접근 가능한지 표시 |

로컬 로그가 새 노트북에 없으면 재현 명령을 남긴다. 비밀값·개인 경로·무관한 대화는 넣지 않는다.
