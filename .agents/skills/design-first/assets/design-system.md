# 디자인 시스템 결정

상태: 사용자와 결정하기 전에는 미정. 하네스가 제품의 디자인을 자동 확정하지 않는다.

- 기준 디자인·참고 화면과 사용할 수 있는 자산:
- 대상 사용자·제품 분위기·사용 환경:
- 색상: 배경·텍스트·주요 동작·상태 의미, 대비 기준:
- 글꼴·크기·굵기·줄간격:
- 간격·레이아웃·반응형 기준:
- 테두리·모서리·그림자·모션:
- 토큰 원본 파일과 코드에서의 사용 방식:
- 공용 컴포넌트 목록·props·상태:
- 로딩·빈 화면·오류·비활성·키보드 포커스:
- 데모 화면과 시각 검증 기준:
- 사용자 결정 날짜와 남은 질문:

UI를 만들 때 기존 토큰과 컴포넌트를 먼저 활용한다.
프로젝트별 값은 프로젝트 자료에 두며 공통 AGENTS.md에 복제하지 않는다.
